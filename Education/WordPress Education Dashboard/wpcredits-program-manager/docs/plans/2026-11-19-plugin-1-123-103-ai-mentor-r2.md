# Plugin 1.123.103: AI Mentor R2, a student's question to their mentor and the first write abilities (implementation plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When Need help? cannot help, a student with a mentor sends the question to that mentor with one press (an email they answer by replying, and the question waiting on the Mentor Report Card until marked answered); every role sees three example questions; and the AI Mentor's tutor gets its first two write abilities, acting only for the signed-in student and answering with record IDs.

**Architecture:** A new module `WPCPM_Student_Questions` (`includes/modules/class-wpcpm-student-questions.php`) owns the switch, who may send, the `wpcpm_question` post type, sending, the email, the Mentor Report Card's list, the privacy tools and its uninstall. `WPCPM_Mentor_Notes` gains a note source for Need help? notes that no count reads as the mentor's. Need help?'s box and page draw the examples, the channel and the send control; the two abilities are thin wrappers over the two modules.

**Tech Stack:** PHP 7.4+ WordPress plugin `wpcredits-program-manager` (prefix `WPCPM_`); WordPress's Abilities API and MCP Adapter 0.7.1 (already wired: `WPCPM_Abilities`, `WPCPM_Ability_Answers`, `WPCPM_MCP`); the plugin's mail stack (`WPCPM_Mail::send()`, `WPCPM_Mail_Templates`, `WPCPM_Mail_Catalog`); the no-WordPress suites `bin/test-*.php` (each ends `ALL PASS` and exits 0); the Docker copy in `~/Projects/wpcredits-docker`; the release script `~/Projects/wpcredits-release/release.py`.

**Spec:** `docs/specs/2026-11-19-ai-mentor-r2-student-questions-design.md`. It is the binding authority: read all of it before any task. Its decisions (section 2) are the product owner's and are never re-asked; section 19 lists the calls he still checks. The code map of 19 November (`.superpowers/session-backups/2026-11-19/ai-mentor-r2/code-map.md` in the main checkout) gives every file and line this plan names.

## Rulings

Where the design leaves a detail open, the plan rules here, once; each task that builds a ruling names it.

1. **Base, number, branch.** Built on main `3214a1da` (1.123.101, live) as **1.123.103**: 1.123.102 is held by the small fixes release (`feature/small-fixes-102`), and whichever deploys second merges main and re-bumps past the then-live version. Branch `feature/ai-mentor-r2`, worktree `.worktrees/ai-mentor-r2`. Commit messages start `AI Mentor R2:`.
2. **The switch.** Setting `handbook_to_mentors`, default `false`, drawn on the Need help? screen after **Questions per person per hour** as a checkbox row: label **Send to mentors**, box text "Let a student send a question to their mentor", description "A student with a mentor can send a question Need help? could not answer to their mentor, who gets an email and sees it on the Mentor Report Card. Leave it off until mentors are told." It joins `defaults()`, the `tool:handbook` scope, `sanitize()` (read with `array_key_exists`, as `handbook_enabled`), `WPCPM_Handbook::settings_keys()` and the guarded flag list at `class-wpcpm-settings.php:1054`. No settings version move. `WPCPM_Student_Questions::switched_on(): bool` is its only reader.
3. **Boot and uninstall.** `WPCPM_Student_Questions::init()` is called from `WPCPM_Mentors::boot()` right after `WPCPM_Mentor_Notes::init()`, so the post type, the handlers and the privacy tools exist whether or not Need help? is on; `WPCPM_Student_Questions::delete_all()` is called from `WPCPM_Mentors::uninstall()` beside `WPCPM_Mentor_Notes::delete_all()`. The class file is required in `wpcredits-program-manager.php` and in `uninstall.php`.
4. **Who may send.** `WPCPM_Student_Questions::mentor_of( $student_user_id ): array|WP_Error` decides it for the control, the send, the notes and both abilities. In order: the switch off (`wpcpm_send_off`); not an account holding `WPCPM_Roles::ROLE_STUDENT` (`wpcpm_not_student`); no Students record ID from `WPCPM_Mentor_Calls::student_record()` (`wpcpm_no_record`); no mentor from `WPCPM_Mentor_Calls::mentor_for_student()` (`wpcpm_no_mentor`); the mentor's `WPCPM_Mentors_Dashboard::get_mentees()` holds no row with that record ID (`wpcpm_mentor_gone`); the row's `is_past` set (`wpcpm_past`). Otherwise `array( 'student' => WP_User, 'mentor' => WP_User, 'student_record' => string, 'mentor_record' => string, 'row' => array )`, `mentor_record` from the mentor's `WPCPM_Mentors_Sync::META_RECORD_ID` user meta. The acting account is always the signed-in one: no caller passes another student.
5. **Post type `wpcpm_question`.** Registered as the notes' type is (`public` false, `show_ui` false, `show_in_rest` false, `rewrite` false, `query_var` false, `exclude_from_search` true, `can_export` false, `capability_type array( 'wpcpm_question', 'wpcpm_questions' )`, `map_meta_cap` true, `supports array( 'author' )`), every row inserted `private` with `wp_insert_post( wp_slash( ... ), true )`. Meta: `_wpcpm_question_student` (Students record ID), `_wpcpm_question_mentor` (mentor user ID), `_wpcpm_question_mentor_record`, `_wpcpm_question_note`, `_wpcpm_question_links` (array), `_wpcpm_question_state` (`waiting` or `answered`), `_wpcpm_question_answered_at` (Unix time), `_wpcpm_question_answered_by` (user ID). `post_content` is the question; `post_title` "Question - {Y-m-d H:i}".
6. **Limits.** Questions: `WPCPM_Student_Questions::PER_DAY = 3` per student per UTC day, through `WPCPM_Ceiling` (key `question_day_<user ID>`, released when the send fails after the claim), and no question whose words equal, by `WPCPM_Typed_Text::same_lines()`, one the student sent in the last `DAY_IN_SECONDS`. Need help? notes: `WPCPM_Mentor_Notes::NEED_HELP_PER_DAY = 10` the same way (key `need_help_day_<user ID>`) and the same 24-hour repeat rule. A limit or a repeat is an answer with `state` `limit` or `duplicate`, not an error.
7. **Lengths.** Question 3 to 400 characters (`WPCPM_Handbook_Assistant::MAX_LENGTH`), note 0 to 600 (`WPCPM_Student_Questions::NOTE_MAX`), Need help? note 3 to 2,000 (`WPCPM_Mentor_Notes::NEED_HELP_MAX`), each read with `sanitize_textarea_field()` and cut, never refused for length after the cut.
8. **Links.** At most five, kept in order, each `esc_url_raw()` and kept only when it is under `home_url( '/' )` or under `https://make.wordpress.org/community/handbook/education/credits/`; any other is dropped silently.
9. **The email.** Catalog ID `student-question-mentor`, `TYPE_MENTOR`, in a new module `MODULE_NEED_HELP = 'need-help'` labelled "Need help?"; its template in a new area file `includes/mail/templates/need-help.php`, added to `WPCPM_Mail_Templates::AREAS`. Subject and body are the spec's section 4 words verbatim (no site-name prefix: the product owner approved these words). Placeholders: `student_first_name`, `mentor_first_name`, `question` (required, body only), `student_note` (optional, body only), `links` (optional, body only: one address a line; its "Need help? showed them:" line drops with it), `student_card_url` (required). Sent with `WPCPM_Mail::send( $mentor, 'student-question-mentor', $build )`, `headers` from `WPCPM_Mail::reply_to( $student )`. The question is saved before the email is sent; a failed email keeps the question waiting and the answer says `state` `sent` with `emailed` false.
10. **Markup the card's script must not read.** No Need help? note and no question carries the classes `wpcpm-note` or `wpcpm-note__meta`: `assets/js/triage.js` counts `.wpcpm-notes__list .wpcpm-note` and reads `.wpcpm-note__meta time[datetime]`. Need help? notes are `li.wpcpm-need-help-note` in their own `ol.wpcpm-need-help-notes` after the notes list; questions are `li.wpcpm-question` in `ol.wpcpm-questions`.
11. **The two abilities.** `NAMES` gains `wpcpm/post-student-message` then `wpcpm/add-mentor-note`, after `wpcpm/search-guides` (ten). A new `WPCPM_Abilities::WRITES` lists both. `definitions()` gives a name in `WRITES` the permission callback `WPCPM_Abilities::student_permitted()` (`mcp_enabled` on and `mentor_of( get_current_user_id() )` not an error) and the annotations `readonly` false, `destructive` false, `idempotent` false; every other name keeps `permitted()` and its read-only annotations. `answer()` logs `array()` as the input for a name in `WRITES`; the log row's records are the student's and the mentor's record IDs. Builders `WPCPM_Ability_Answers::student_message( $input = null )` and `mentor_note( $input = null )`. The MCP server's description becomes "Answers from the WPCredits Program Manager's own records, and two writes a signed-in student makes for themselves."
12. **Need help?'s reply.** `POST wpcpm/v1/handbook/ask` adds `found` (bool, `ask()`'s), `nothing` (bool: `found` false and no sources, the nothing sentence), `channel` (`array( 'url', 'label' )` from `guides()` for the box's audience, the `slack` and `chat` keys) and `may_send` (bool: the audience is `student` and `mentor_of()` of the signed-in account is not an error). The question sent is the question asked; the links sent are the reply's `sources` links.
13. **The send route.** `POST wpcpm/v1/handbook/send`, args `question` (required string), `note` (string), `links` (array of strings), permission `WPCPM_Handbook_Assistant::user_can_ask()` and `mentor_of()` not an error, callback `WPCPM_Student_Questions::send()`; reply `array( 'state', 'message' )` with the spec's sentences. The Need help? page's no-script form posts to `admin-post.php`, action `wpcpm_send_question`, nonce `wpcpm_send_question`, and comes back to the page with a `WPCPM_Flash` message.
14. **Words.** Every string a person reads is the spec's section 12 words or, where it names none, US English, plain hyphens, full product names, "Administrators", "Need help?" for the tool; no screen a mentor or a student sees says "AI Mentor". The two limits' sentences: "You have sent your mentor three questions today. Ask in the WordPress Credits Slack channel, or try again tomorrow." and "You sent your mentor this question in the last day. They will reply by email."
15. **Held guide text.** The Student guide's Send to my mentor and the Mentor guide's questions, email, Mark as answered and Need help? notes are written as `docs/sections/16-student-send-to-mentor.md` and `docs/sections/27-mentor-questions.md`, listed in no guide's `parts` in `bin/docs-guides.php` (so the build never reads them), each opening with the line `<!-- Held until Send to mentors is switched on: add to parts in bin/docs-guides.php in the docs release that follows. -->`, with no `{{clip:}}` token.
