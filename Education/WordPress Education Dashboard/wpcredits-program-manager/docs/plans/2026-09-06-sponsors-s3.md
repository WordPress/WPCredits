# Sponsors Phase S3: sponsor posts (plugin 1.95.0, theme 1.22.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A sponsor's accounts write posts in the wp-admin block editor and can never publish; a program manager publishes or returns them; published posts reach students and mentors on their Report Cards and in the sponsor's category, carrying the company's name rather than a person's.

**Architecture:** One new class, `WPCPM_Sponsor_Posts`, holds the per-sponsor posting flag and the three per-account capabilities, the two category terms, the editor fence (hooks added only for a sponsor member without `CAP_MANAGE`), the Posts card on the Sponsor Dashboard, the byline, the publish and return handlers, and the list of guides under an offer in the Tools section. `WPCPM_Content_Access` gains one level, "Students and mentors", whose grant is either of two marker capabilities. Everything else is a call into the new class behind a `class_exists()` guard, the way the Sponsor Dashboard's card loop already names it.

**Tech Stack:** WordPress 6.6+ (PHP 7.4), plain-PHP suites under `bin/`, the plugin's own stylesheets plus the block theme's `dashboard.css` and `style.css`.

**Spec:** `docs/specs/2026-09-04-sponsors-module-design.md`, sections 1 (decisions 6, 7), 3 (decision 5), 4, 7, 11 and 15. The spec is the authority; this plan argues from it.

## Global Constraints

- No em dash or en dash anywhere: code, comments, docs, readme, CSS. A plain hyphen. `bash bin/check-standards.sh` and the theme's `php bin/check-selectors.php` fail on one.
- US English in every string a person reads (WordPress writing style guide): canceled, color, center. `bin/check-spelling.php` runs inside `check-standards.sh`.
- Full product names: "Student Report Card", "Mentor Report Card", "Institution Dashboard", "Sponsor Dashboard", "Administrator Dashboard".
- Test data uses the address `maciej@a8c.com` and no other address; record IDs in fixtures are fakes shaped `rec` + 14 alphanumerics (for example `recSPN00000000001`).
- Sponsors never see a student's name; nothing about a post's readers is counted or shown to a sponsor. A sponsor account can never reach `publish_posts`, `edit_others_posts` or `edit_published_posts`.
- Capabilities for posting go on the account with `WP_User::add_cap()`, never on the `wpcpm_sponsor` role.
- Every handler: capability or membership first, then the nonce keyed to the object it acts on, then the policy decision, then the act, then one flash and a redirect. Every refusal is the one sentence `WPCPM_Sponsor_Policy::refusal()` gives.
- WordPress coding standards: tabs, spaces inside parentheses, Yoda conditions, `esc_*` on every printed value, prose comments that say why.
- Versions: plugin 1.95.0 in the header, `WPCPM_VERSION`, `readme.txt` (Stable tag and a `= 1.95.0 =` entry), `blocks/sponsor-dashboard/block.json`. Theme 1.22.0 in `style.css` and `readme.txt` with a `= 1.22.0 =` entry. Bumped in the last task of each repository, not before.
- After any edit under `docs/sections/`, run `php bin/build-docs.php`.
- Checks that must be green before a task is complete: every `bin/test-*.php` suite, `bash bin/check-standards.sh` (0 errors; 91 pre-existing warnings are known), `php bin/check-references.php`, `php bin/check-spelling.php`; for the theme, `php bin/check-selectors.php`.
- Nothing runs against the live site from a task. Deploy, mirror and notes are the controller's.
- Theme CSS: declarations alphabetical inside a rule; every value copied from an existing rule and the source named in the comment; reading text never below 14px and never `--wpc-ink-50`; control borders `--wpc-control-border`; outlines and rings `--wpc-brand`; a class the theme dresses must be printed by the plugin.

## Decisions this plan makes beyond the spec (rulings)

1. **Publish and Return live on the Sponsor Dashboard's Posts card for a manager viewing a sponsor**, using the two handlers the spec names (`ACTION_POST_PUBLISH`, `ACTION_POST_RETURN`). Phase S6's Administrator Dashboard queue reuses the same handlers. Why: the spec puts the queue in S6 but wants the handlers and their tests in S3; a manager needs a place to press them now.
2. **A member's save always pins the level to `students_mentors`, the categories to Sponsors plus the sponsor's child, and the `_wpcpm_sponsor` stamp**, on `save_post_post` (priority 20) and on `rest_after_insert_post`. Why: the block editor saves over REST, where terms and meta are written after the post row, so `save_post` alone runs too early; and a member cannot edit a published post (`edit_published_posts` is never granted), so forcing the level on every member save never undoes a manager's widening.
3. **Version bumps touch `blocks/sponsor-dashboard/block.json` only among the block manifests**: the other five are not lock-stepped today (1.92.0, 1.72.1, 1.72.0, 1.12.0, 1.12.0) and this phase changes only the sponsor page.
4. **Theme 1.22.0 ships alongside**: the Posts card rows, the guides list in the Tools section and the byline banner are new classes, and the theme is the skin of every plugin class. The spec's version table predates that rule.
5. **The editor is trimmed for members**: `edit_posts` opens the Comments and Tools menus to a Contributor, so both are removed, with the toolbar's Comments node; the wp-admin home already redirects sponsor accounts to the Sponsor Dashboard.
6. **Guides are listed once per sponsor in the Tools section**, under that sponsor's first offer in the list, so two offers from one company do not print the same guides twice.
7. **The child category is renamed from the sync's index write point** by comparing the rows held before with the rows just read; no new action or filter is introduced (no sponsor module fires one today).
8. **`WPCPM_Sponsor_Members::attach()` and `detach()` call `WPCPM_Sponsor_Posts::apply_caps()` / `drop_caps()` behind `class_exists()`**, so the members suite stays green as it is and provisioning applies the flag with no second code path.
9. **The parent category is found by slug (`sponsors`) each time, not stored**; only the child term id is kept, in `wpcpm_sponsor_term_<record>`.
10. **The byline banner is skipped when the viewer cannot read the post**: the access gate at priority 5 has already replaced the content with its notice, and a banner above a refusal would name the sponsor to someone the level refuses.

	 * @return int Term id, or 0.

		$record = trim( (string) $record );

		if ( ! WPCPM_Mentors_Sync::is_record_id( $record ) ) {
			return 0;
		}

		$have = self::term_of( $record );

		if ( $have > 0 ) {
			return $have;
		}

		$parent = self::parent_term_id();

		if ( $parent < 1 ) {
			return 0;
		}

		$row  = WPCPM_Sponsors_Index::row( $record );

		$base = sanitize_title( $name );

		$n    = 2;

		while ( term_exists( $slug, 'category' ) ) {
			$slug = $base . '-' . $n;
			++$n;

			if ( $n > 50 ) {
				return 0;
			}
		}

		$made = wp_insert_term( $name, 'category', array( 'slug' => $slug, 'parent' => $parent ) );

		if ( is_wp_error( $made ) ) {
			return 0;
		}

		update_option( self::OPT_TERM_PREFIX . $record, (int) $made['term_id'], false );

		return (int) $made['term_id'];

	/**
	 * A sponsor's posts by its stamp, newest change first. Filters are suppressed on purpose: a

	 * would hide the sponsor's own list from the sponsor.

	 * @return WP_Post[]
	 */
	public static function posts_of( $record, array $statuses = array( 'draft', 'pending', 'publish' ), $limit = self::CARD_LIMIT ) {
		$record = trim( (string) $record );

		if ( ! WPCPM_Mentors_Sync::is_record_id( $record ) ) {
			return array();
		}

		$found = get_posts(
			array(
				'post_type'        => 'post',
				'post_status'      => $statuses,
				'numberposts'      => max( 1, (int) $limit ),
				'orderby'          => 'modified',
				'order'            => 'DESC',
				'meta_key'         => WPCPM_Sponsor_Policy::META_POST_SPONSOR, // phpcs:ignore WordPress.DB.SlowDBQuery.slow_db_query_meta_key
				'meta_value'       => $record, // phpcs:ignore WordPress.DB.SlowDBQuery.slow_db_query_meta_value
				'suppress_filters' => true,
			)
		);

		return array_values( array_filter( (array) $found, static function ( $post ) { return $post instanceof WP_Post; } ) );

	/**
	 * The shared opening of publish and return: the post, its stamp, the nonce keyed to the
	 * post, the claim (metered) on the stamp's sponsor, and the decision on the post itself.
	 *
	 * @param string $action `ACTION_POST_PUBLISH` or `ACTION_POST_RETURN`.
	 * @return array `post`, `record`, `claim`; leaves on any refusal.
	 */
	private static function begin( $action ) {
		if ( ! is_user_logged_in() ) {
			self::leave( 'refused' );
		}

		$post_id = WPCPM_Request::posted_id( 'wpcpm_post' );
		$post    = $post_id > 0 ? get_post( $post_id ) : null;
		$record  = $post instanceof WP_Post ? trim( (string) get_post_meta( $post->ID, WPCPM_Sponsor_Policy::META_POST_SPONSOR, true ) ) : '';

		if ( ! $post instanceof WP_Post || 'post' !== $post->post_type || ! WPCPM_Mentors_Sync::is_record_id( $record ) ) {
			self::leave( 'refused' );
		}

		check_admin_referer( $action . '_' . (int) $post->ID );

		$claim = WPCPM_Sponsor_Roster::claim( $record, WPCPM_Sponsor_Policy::ACT_PUBLISH_POST );

		if ( is_wp_error( $claim ) ) {
			self::leave( 'refused' );
		}

		$decision = WPCPM_Sponsor_Policy::decide( WPCPM_Sponsor_Policy::ACT_PUBLISH_POST, WPCPM_Sponsor_Policy::subject_post( $post ) );

		if ( empty( $decision['allowed'] ) ) {
			self::leave( 'refused' );
		}

		if ( 'pending' !== $post->post_status ) {
			self::leave( 'post-not-pending', $record );
		}

		return array(
			'post'   => $post,
			'record' => $record,
			'claim'  => $claim,
		);
	}

	/**

	public static function handle_publish() {

				'message'  => __( 'A sponsor post was published.', 'wpcredits-program-manager' ),
				'data'     => array( 'post' => (int) $post->ID ),
			)
		);

		self::leave( 'post-published', $opened['record'] );
	}

	public static function handle_flags() {
		if ( ! current_user_can( WPCPM_Roles::CAP_MANAGE ) ) {

	/**
	 * The sponsor a post in the loop belongs to, or ''.
	 *
	 * @return string
	 */
	private static function record_in_loop() {
		$post = get_post();

		if ( ! $post instanceof WP_Post || 'post' !== $post->post_type ) {
			return '';
		}

		$record = trim( (string) get_post_meta( $post->ID, WPCPM_Sponsor_Policy::META_POST_SPONSOR, true ) );

		return WPCPM_Mentors_Sync::is_record_id( $record ) ? $record : '';
	}

	/**
	 * `the_author` and `get_the_author_display_name`: a sponsor post carries the company, not
	 * a person's name (spec 7.5; the author archive is already closed by WPCPM_Privacy_Guard).
	 *
	 * @param string $name The display name WordPress would print.
	 * @return string
	 */
	public static function filter_author_name( $name ) {
		$record = self::record_in_loop();

		if ( '' === $record ) {
			return $name;
		}

		$row = WPCPM_Sponsors_Index::row( $record );

		return is_array( $row ) && '' !== trim( (string) $row['name'] )
			? trim( (string) $row['name'] )
			: __( 'A sponsor of the program', 'wpcredits-program-manager' );
	}

	/**
	 * `the_content`, priority 6: the banner above a sponsor post, for a reader the level admits.
	 *
	 * @param string $content The content after the access gate at 5.
	 * @return string
	 */
	public static function filter_content( $content ) {
		if ( ! is_singular( 'post' ) || ! in_the_loop() || ! is_main_query() ) {
			return $content;
		}

		$record = self::record_in_loop();

		if ( '' === $record || ! WPCPM_Content_Access::can_view( get_post() ) ) {
			return $content;
		}

		$row  = WPCPM_Sponsors_Index::row( $record );
		$row  = is_array( $row ) ? $row : WPCPM_Sponsors_Index::empty_row();
		$name = '' !== trim( (string) $row['name'] ) ? trim( (string) $row['name'] ) : __( 'A sponsor', 'wpcredits-program-manager' );
		$site = WPCPM_Field_Value::clean_url( (string) $row['website'] );
		$logo = WPCPM_Sponsors_Index::display_logo( $record );

		$html = '<aside class="wpcpm-sponsor-byline">';

		if ( is_array( $logo ) && ! empty( $logo['url'] ) ) {
			$html .= sprintf( '<span class="wpcpm-sponsor-byline__logo"><img src="%s" alt="" loading="lazy" decoding="async" /></span>', esc_url( $logo['url'] ) );
		} else {
			$html .= sprintf( '<span class="wpcpm-sponsor-byline__initials" aria-hidden="true">%s</span>', esc_html( mb_substr( $name, 0, 1 ) ) );
		}

		$company = '' !== $site
			? sprintf( '<a href="%1$s" rel="external noopener">%2$s</a>', esc_url( $site ), esc_html( $name ) )
			: esc_html( $name );

		$html .= sprintf(
			'<p class="wpcpm-sponsor-byline__text">%s</p>',
			/* translators: %s: the company name, possibly linked. */
			sprintf( esc_html__( 'A guide from %s, a sponsor of the WordPress Credits program.', 'wpcredits-program-manager' ), $company )
		);
		$html .= '</aside>';

		return $html . $content;
	}
