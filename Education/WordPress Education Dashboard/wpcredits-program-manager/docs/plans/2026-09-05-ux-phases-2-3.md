# UX Review Phases 2 and 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish what the UX and accessibility review of 5 September 2026 asked for after phase one: every hint tied to its control, required fields marked, the grades laid out to be read, hints under the controls they explain, choice targets at 24px, the theme's type scale applied to the last small rules, the read-only report as text rows, the last hairline gone, and the theme's grays and tints on the WordPress.org design system's values.

**Architecture:** Plugin 1.94.6 changes two renderers (`WPCPM_Student_Report_Form::render_field()` and the `$field` closure in `WPCPM_Sponsor_Offers`) plus the spec array of the report form; nothing else in PHP moves. Theme 1.20.0 is a rule-by-rule pass over `assets/css/dashboard.css` and a token change in `theme.json`, verified with the server-side capture and computed-style method already used for the dashboards. The Inter typeface is a separate, gated task at the end: it ships only on the owner's yes.

**Tech Stack:** PHP 7.4+ WordPress plugin, plain-PHP test suites in `bin/`, phpcs (`bash bin/check-standards.sh`, which also runs the dash and US-spelling checks), the theme's `php bin/check-selectors.php` (classes, tokens, dashes), `bash bin/build` for the plugin zip.

**Spec:** the review artifact *WPCredits Dashboard UX Review* (https://claude.ai/code/artifact/27cd60c3-1006-490f-b092-bb4d8695bd4a), sections 3 to 7, and the vault note *Institutions module*, section "The UX review and phase one of its fixes". Phase one shipped as plugin 1.94.3 to 1.94.5 and theme 1.19.2 to 1.19.5; this plan is what those releases did not do.

## Global Constraints

- No em or en dashes anywhere (plain hyphens); `check-standards.sh` and `check-selectors.php` fail on one.
- US English in every string a person reads (`bin/check-spelling.php` runs inside `check-standards.sh`); full product names: "Student Report Card", "Mentor Report Card", "Institution Dashboard", "Sponsor Dashboard", "Administrator Dashboard".
- Reading text is never under 14px and never in `--wpc-ink-50`; uppercase eyebrows are 13px or 12px; chips, counts and badges are 12px; nothing is 10px or 11px.
- Every form control's border is `--wpc-control-border` (theme) or `--wpcpm-control-border` (plugin base); 3:1 against the page.
- A block class name belongs to one dashboard's markup only (1.94.5 lesson: `wpcpm-mentor-card` is the student's card, `wpcpm-mentor-tile` the sponsor's); every class the theme dresses must be printed by the plugin or the theme (`check-selectors.php`).
- Versions: plugin **1.94.6** (`wpcredits-program-manager.php` header and `WPCPM_VERSION`, `readme.txt` Stable tag and a `= 1.94.6 =` entry), theme **1.20.0** (`style.css` Version, `readme.txt` Stable tag and entry). Theme and plugin are separate git repositories; commit each in its own.
- The Inter task (Task 10) does not run unless the owner has said yes in the conversation that dispatches it.
- Every test send, test student and test sponsor uses `maciej@a8c.com` and no other address. Nothing destructive against wordpresseducation.org.
- Deploy by streaming both zips over ssh stdin, compare checksums, `wp plugin install --force` / `wp theme install --force`, read `--field=version` back before any page is opened; then mirror to `WordPress/WPCredits` trunk under `Education/WordPress Education Dashboard/` (commit and push as separate calls).

Add the method after `render_field()`:

```php
	/**
	 * A field for a reader, not a writer: the label and the value as a row.
	 *
	 * A mentor or a manager reads the card and never fills it in, and a disabled box says
	 * "something is wrong here" while lowering the contrast of what it holds. The row is the
	 * shape the profile table already has (phase two of the type review, 1.94.6).
	 *
	 * @param string $id    Control id, kept as the row's id so links to a field still land.
	 * @param array  $spec  Field spec.
	 * @param mixed  $value Stored value.
	 * @param string $type  Field type.
	 */
	private static function render_read_only( $id, array $spec, $value, $type ) {
		$text = is_scalar( $value ) ? trim( (string) $value ) : '';

		if ( 'checkbox' === $type ) {
			$text = self::is_ticked( $value ) ? __( 'Yes', 'wpcredits-program-manager' ) : __( 'No', 'wpcredits-program-manager' );
		}

		if ( '' === $text ) {
			$html = '<span class="wpcpm-field__value wpcpm-field__value--empty">' . esc_html__( 'Not filled in', 'wpcredits-program-manager' ) . '</span>';
		} elseif ( 'url' === $type ) {
			$html = sprintf( '<span class="wpcpm-field__value"><a href="%1$s" target="_blank" rel="noopener noreferrer">%2$s</a></span>', esc_url( $text ), esc_html( $text ) );
		} elseif ( 'richtext' === $type ) {
			$html = '<span class="wpcpm-field__value">' . wp_kses_post( $text ) . '</span>';
		} else {
			$html = '<span class="wpcpm-field__value">' . nl2br( esc_html( $text ) ) . '</span>';
		}

		printf(
			'<p class="wpcpm-field wpcpm-field--read wpcpm-field--%1$s" id="%2$s"><span class="wpcpm-field__label">%3$s</span>%4$s</p>',
			esc_attr( $type ),
			esc_attr( $id ),
			esc_html( $spec['label'] ),
			$html // phpcs:ignore WordPress.Security.EscapeOutput.OutputNotEscaped -- Built above from escaped parts.
		);
	}
```

Check the suite's stubs: `nl2br`, `wp_kses_post` may need stubs in `bin/test-report-form.php` (`function wp_kses_post( $s ) { return $s; }`). The team branch keeps `render_teams()` with `$can = false` (disabled tiles).
