## Decisions this plan makes (rulings)

1. **`WPCPM_Form_Stash` is a static class configured by an array the caller builds from its own constants**, not a base class: both application classes are `final` and already share the guard the same way. The array carries `url`, `outcomes` (the slugs that may travel bare), `query_outcome`, `query_stash`, `prefix`, `minutes`, `one_shot` (the outcomes deleted as they are read). Blank detection stays in each class (`is_blank()`), passed as a closure, because the two classes define blank identically today and may not tomorrow.
2. **The menu bubble caches for sixty seconds in the transient `wpcpm_sponsors_attention`** and forgets itself when an application's state changes (`WPCPM_Sponsor_Application::add_event()` runs on every transition), when a sponsor agreement's state meta changes and when a post of the sponsor posts' kind changes status (`updated_post_meta`, `added_post_meta`, `transition_post_status`). Sixty seconds, because the bubble is drawn on every admin page and the three queries behind it were the review's finding; a lag of a minute after a change made by somebody else is what a cache means.
3. **The two-part dwell token goes.** It was accepted for one deploy window (twelve hours from 6 September 2026); every token of that shape is stale by now, so refusing it changes nothing for anybody.
4. **Recently decided is bounded by a decision-time meta, `_wpcpm_sapp_decided`**, written by `add_event()` for the three terminal events and removed on reopen, queried newest first with `numberposts` `QUEUE_MAX + 1` (one over, so the sentence can say "the 50 most recent" without counting every row). The retention run keeps reading the event history (`decided_at()`), which is the record; the meta is the index. A one-time backfill on `admin_init`, behind the option flag `wpcpm_sapp_decided_backfilled`, writes the meta for any decided row that lacks it (none exist on the live site today; the code does not know that).
5. **The docs build escapes `&`, `<` and `>` in section text before its inline markup**, so a literal `<record>` in a section reaches the HTML as text. Quotes are left alone (`ENT_NOQUOTES`): the sections use them as prose and the build never puts section text in an attribute. The Markdown outputs are untouched: they carry the sections as written.
6. **The institution agreement gets the retry the sponsor twin has had since S4**: `WPCPM_Institution_Agreement::retry_airtable()` resends, for every record marked `_wpcpm_agr_airtable_pending`, the cells the site's own state says the base should hold, and clears the mark when the write lands; the institutions sync calls it at the end of its nightly run, behind `method_exists()`. Why: the mark has been written on every failed PATCH since the institutions module shipped and read by nothing, so a base that missed one write stays wrong until somebody notices.
7. **The `.wpcpm-review__form--return` modifier is removed**, not dressed: three printf sites print it, no stylesheet has ever had a rule for it, and a class with no rule and no script is a class the next reader will look for in vain.
8. **`WPCPM_Image_Upload::store()` deletes the copy it made when `wp_insert_attachment()` refuses**, so a failed store leaves the uploads directory as it found it. The re-saved temporary copy is already deleted before the insert; this closes the other half.
9. **The dashboard suite's stubs take the real shapes**: index rows keyed and carrying `record_id`, the `is_live()` stub reading `wp_date()` like the real one, the codes `counts()` stub answering `total` too. The checks do not change; only what a future reader of the stub is told.

```php
<?php
/**
 * The stash-and-redirect machinery the two public application forms share.
 *
 * @package WPCreditsProgramManager
 */

if ( ! defined( 'ABSPATH' ) ) {
	exit;
}

/**
 * A handler that has read a form answers with a redirect back to the page, and what the page
 * must draw travels one of two ways: an outcome the page knows by its slug travels bare in the
 * address, and anything with the sender's own words in it travels behind a random id in a
 * transient, so nothing typed is ever in a URL. The institution form (S1 of the institutions
 * module) and the sponsor form (Sponsors S5) each carried a copy of this; the S5 review asked
 * for one (clean-up 1.98.1). Each form describes itself in an array the caller builds from
 * its own constants: `url`, `outcomes`, `query_outcome`, `query_stash`, `prefix`, `minutes`,
 * `one_shot`. Blank detection stays the caller's: the two forms agree on it today and are free
 * not to tomorrow.
 */
final class WPCPM_Form_Stash {

	/**
	 * Redirect back to the form with the outcome, and the stash behind a transient when it
	 * holds anything worth keeping.
	 *
	 * An outcome with nothing behind it travels bare, and only a slug the form knows may:
	 * anything else goes behind a transient, which is also what keeps `sent` on the stash it
	 * must have.
	 *
	 * @param array    $form     The form's description (see the class docblock).
	 * @param string   $outcome  The outcome slug.
	 * @param array    $stash    What the page needs to draw: values, problems, a reference.
	 * @param callable $is_blank Says whether one value is blank.
	 */
	public static function bounce( array $form, $outcome, array $stash, callable $is_blank ) {
		$url   = '' !== (string) $form['url'] ? (string) $form['url'] : home_url( '/' );
		$stash = self::keep( $stash, $is_blank );

		if ( empty( $stash ) && in_array( (string) $outcome, (array) $form['outcomes'], true ) ) {
			wp_safe_redirect( add_query_arg( array( (string) $form['query_outcome'] => (string) $outcome ), $url ) );

			exit;
		}

		$stash['outcome'] = (string) $outcome;

		wp_safe_redirect( add_query_arg( array( (string) $form['query_stash'] => self::put( $form, $stash ) ), $url ) );

		exit;
	}

	/**
	 * What of a stash is worth a transient, or an empty array when none of it is.
	 *
	 * Blank answers go first, then blank keys: a form redrawn from a stash treats an absent
	 * value and an empty one identically, so the difference between "typed something" and "a
	 * POST with no body" is what decides whether two rows are written at all.
	 *
	 * @param array    $stash    What the handler wants to hand back.
	 * @param callable $is_blank Says whether one value is blank.
	 * @return array The same, minus the blanks.
	 */
	public static function keep( array $stash, callable $is_blank ) {
		if ( isset( $stash['values'] ) && is_array( $stash['values'] ) ) {
			foreach ( $stash['values'] as $column => $value ) {
				if ( call_user_func( $is_blank, $value ) ) {
					unset( $stash['values'][ $column ] );
				}
			}
		}

		foreach ( $stash as $key => $value ) {
			if ( is_array( $value ) ? empty( $value ) : call_user_func( $is_blank, $value ) ) {
				unset( $stash[ $key ] );
			}
		}

		return $stash;
	}

	/**
	 * Put one stash behind a random id and answer with the id.
	 *
	 * The id is derived from nothing (not the address, not the reference, not the session): it
	 * is the only thing that travels. Lowercased because it comes back through
	 * `WPCPM_Request::key()`, which lowercases.
	 *
	 * @param array $form  The form's description.
	 * @param array $stash What to keep.
	 * @return string The id.
	 */
	public static function put( array $form, array $stash ) {
		$id = strtolower( wp_generate_password( 32, false, false ) );

		set_transient( (string) $form['prefix'] . $id, $stash, (int) $form['minutes'] * MINUTE_IN_SECONDS );

		return $id;
	}

	/**
	 * Read the stash this request carries, if it carries one.
	 *
	 * A one-shot outcome (a confirmation that names a reference) is deleted as it is read, so
	 * a reload or a forwarded link shows the plain form; a failed attempt is not, because it
	 * holds only what the sender typed and losing it on a reload is the thing this exists to
	 * avoid. A bare outcome is answered only when the form knows the slug.
	 *
	 * @param array $form The form's description.
	 * @return array The stash, `array( 'outcome' => slug )` for a bare one, or an empty array.
	 */
	public static function read( array $form ) {
		$id = WPCPM_Request::key( (string) $form['query_stash'] );

		if ( '' !== $id ) {
			$stash = get_transient( (string) $form['prefix'] . $id );

			if ( is_array( $stash ) ) {
				$outcome = isset( $stash['outcome'] ) ? (string) $stash['outcome'] : '';

				if ( in_array( $outcome, (array) $form['one_shot'], true ) ) {
					delete_transient( (string) $form['prefix'] . $id );
				}

				return $stash;
			}
		}

		$said = WPCPM_Request::key( (string) $form['query_outcome'] );

		return in_array( $said, (array) $form['outcomes'], true ) ? array( 'outcome' => $said ) : array();
	}
}
```
