# Release 1.122.23: the sponsor's PDF upload, the five kept oddities, names as people read them, Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A small release of fixes to the email and upload code 1.122.22 ships: a sponsor's member can upload the signed Collaboration Agreement on the Sponsor Dashboard; the five oddities E4 kept word for word are mended; every email prints a name as a person reads it, in its body and in its subject, and a Reply-To keeps every character of the name it carries; an edited email ends as its shipped body ends; and the courtesy scan's notes read as words an Administrator understands, in the email and on the three screens that list them. Every other byte any email says stays as recorded.

**Architecture:** Fixes in place, each where the code decides it. The PDF check (`WPCPM_Pdf_Check::named_pdf()`) asks WordPress's name-and-type map with the allowed types narrowed to PDF for that one call, so the sponsor posts' fence keeps the media library to images and no longer reaches the agreement. The template registry reads every value back as a person reads it in one place (`WPCPM_Mail_Templates::fill()`), for every email of every area, and gives an edit the shipped body's ending where an edit is read (`text_of()`); the mail layer marks the subject of every email the registry fills plain text in one place (`WPCPM_Mail::hand_off()`), so a name reads as typed there too, and its `reply_to()` reads the name back and writes one it cannot quote as RFC 2047 encoded words. The low codes count in words, the Offers card's line goes when there is no card, a nameless Administrator is "an Administrator", the invitation with nobody to name as its sender becomes an email of its own, both invitations' promise of a reply is a value, the two interest emails name the site, and the scan's notes are worded by `WPCPM_Pdf_Check::in_words()`. The three recordings E2, E3 and E4 made stay frozen; two new recordings, made once from 1.122.22 before anything moves, hold the inputs the release needs that the old ones lack; and each suite lists every email the release changes on purpose, with its item and the exact text, so an email that changes without a line there fails.

**Tech Stack:** WordPress 7.1 plugin PHP (7.4 and 8.x); the plugin's `bin/test-*.php` suites (plain PHP with stubs); `WPCPM_Pdf_Check`, `WPCPM_Sponsor_Posts::limit_mimes()`, `WPCPM_Mail` (`send()`, `send_to()`, `hand_off()`, `subject()`, `reply_to()`), `WPCPM_Mail_Templates` and `WPCPM_Mail_Catalog` as 1.122.22 made them; the recordings `bin/fixtures/invitations-1-122-18.json`, `calls-reports-1-122-20.json` and `institutions-sponsors-1-122-21.json`; WP-CLI for the translation template.

/**
 * Core's `wp_check_filetype_and_ext()` for the files this suite posts: the name's extension against
 * the map given (or the allowed types), the bytes read by fileinfo, which must say the same type, and
 * then, as core asks of every file, a type the account signed in may upload.
 *
 * @param string     $file     The file on disk.
 * @param string     $filename The name it came with.
 * @param array|null $mimes    The map the caller allows.
 * @return array
 */
function wp_check_filetype_and_ext( $file, $filename, $mimes = null ) {
	$ext  = false;
	$type = false;

	foreach ( null === $mimes ? get_allowed_mime_types() : $mimes as $extensions => $mime ) {
		if ( preg_match( '!\.(' . $extensions . ')$!i', (string) $filename, $found ) ) {
			$ext  = strtolower( $found[1] );
			$type = $mime;
			break;
		}
	}

	if ( $type && function_exists( 'finfo_open' ) && is_readable( $file ) ) {
		$finfo = finfo_open( FILEINFO_MIME_TYPE );
		$real  = $finfo ? (string) finfo_file( $finfo, $file ) : '';

		if ( '' !== $real && $real !== $type ) {
			$ext  = false;
			$type = false;
		}
	}

	// The mime type must be allowed.
	if ( $type && ! in_array( $type, get_allowed_mime_types(), true ) ) {
		$ext  = false;
		$type = false;
	}

	return array( 'ext' => $ext, 'type' => $type, 'proper_filename' => false );
}

/**
 * A case's emails as 1.122.23 sends them: as recorded, with the changes `changes()` lists for it
 * made in turn. A pair whose recorded text an email does not hold is noted in `$GLOBALS['stale']`,
 * which a check below holds empty: a change listed is a change made.
 *
 * @param string $case     The case.
 * @param array  $recorded Its emails, as recorded.
 * @return array
 */
function as_changed( $case, array $recorded ) {
	foreach ( changes() as $row ) {
		if ( $case !== $row['case'] ) {
			continue;
		}

		if ( isset( $row['emails'] ) ) {
			$recorded = $row['emails'];
			continue;
		}

		foreach ( $recorded as $n => $mail ) {
			// A row may name the emails of its case it changes, by their place in the recording.
			if ( isset( $row['only'] ) && ! in_array( $n, $row['only'], true ) ) {
				continue;
			}

			foreach ( $row['replace'] as $field => $pairs ) {
				foreach ( $pairs as $old => $new ) {
					$was            = $mail[ $field ];
					$mail[ $field ] = str_replace( (string) $old, $new, $mail[ $field ] );

					if ( $mail[ $field ] === $was ) {
						$GLOBALS['stale'][] = $case . ' #' . $n . ' ' . $field . ': ' . $old;
					}
				}
			}

			$recorded[ $n ] = $mail;
		}
	}

	return $recorded;
}

   The header script (invented names and `example.test` addresses; kept outside the site, piped to `wp eval-file -`):

   ```php
   <?php
   // Builds three Reply-To headers as the plugin does, and prints what PHPMailer would write for each.
   // Nothing is sent and nothing is stored: the mail log's filters are taken off for this process, and
   // pre_wp_mail answers before any mailer runs.
   require_once ABSPATH . WPINC . '/PHPMailer/PHPMailer.php';
   require_once ABSPATH . WPINC . '/PHPMailer/Exception.php';
   remove_all_filters( 'wp_mail' );
   remove_all_filters( 'pre_wp_mail' );
   add_filter(
   	'pre_wp_mail',
   	static function ( $answer, $atts ) {
   		$mailer = new PHPMailer\PHPMailer\PHPMailer( true );
   		$mailer->setFrom( 'wordpress@example.test', 'Header check' );
   		$mailer->addAddress( 'nobody@example.test' );
   		foreach ( (array) $atts['headers'] as $header ) {
   			list( , $content ) = explode( ':', trim( $header ), 2 );
   			foreach ( explode( ',', $content ) as $address ) {
   				$name = '';
   				if ( preg_match( '/(.*)<(.+)>/', $address, $parts ) ) {
   					$name    = $parts[1];
   					$address = $parts[2];
   				}
   				$mailer->addReplyTo( trim( $address ), $name );
   			}
   		}
   		foreach ( explode( "\n", $mailer->createHeader() ) as $line ) {
   			if ( 0 === strpos( $line, 'Reply-To:' ) ) {
   				echo $line, "\n";
   			}
   		}
   		return true;
   	},
   	10,
   	2
   );
   foreach ( array( 'Ida Admin', 'Gus &amp; Gwen &lt;Ops', "Omar O'Admin, Ops" ) as $name ) {
   	$person               = new WP_User();
   	$person->display_name = $name;
   	$person->user_email   = 'reply@example.test';
   	wp_mail( 'nobody@example.test', 'Header check', 'Nothing is sent.', WPCPM_Mail::reply_to( $person ) );
   }
   ```
